# Сборка и тестирование

## Запуск из исходников

Windows x64, Python 3.12 x64, английский компонент Windows OCR.
PowerShell из корня репозитория:

```powershell
python -m venv .venv
& ./.venv/Scripts/python.exe -m pip install -r requirements.txt
& ./.venv/Scripts/python.exe scripts/prepare_data.py
& ./.venv/Scripts/python.exe main.py
```

Словари лежат в `data/bundled-dictionaries.zip`. Скрипт проверяет SHA-256 и
восстанавливает три SQLite-базы и исходный TEI без сети. Уже существующий файл
с другим содержимым не заменяется. Сгенерированные базы не коммитятся в Git.
Лицензии баз остаются CC BY-SA / WordNet, независимо от упаковки в ZIP.

Иконки отметки и выбора лежат в `assets/icons`: исходные SVG и готовые PNG.
После изменения SVG выполните `python scripts/render_ui_icons.py`.
Приложение использует PNG, поэтому портативной сборке не нужен плагин Qt SVG.

## Тесты

```powershell
$env:PYTHONUTF8 = '1'
& ./.venv/Scripts/python.exe -m unittest discover -s tests -v
```

Тесты используют временные профили и подставленные сетевые ответы, не реальные
платные аккаунты. Тесты окон могут кратковременно показывать собственные окна.
Приложение загружает SentencePiece/CTranslate2 до Qt/WinRT для совместимости DLL.
CI проверяет быстрый набор логики, авторизации с mock-ответами и сериализации
на Windows; полноэкранные окна и настоящие игры нужно проверять отдельно.

## EXE и установщик

```powershell
./build.ps1
./build-installer.ps1
```

Первая команда устанавливает закреплённые зависимости в `.venv` и собирает
`dist/Lexora`. Вторая создаёт `dist/Lexora-0.6.34-Setup.exe` с полным содержимым
portable-папки. `Lexora.spec` и `Installer.spec` хранятся в Git.
Запуск готового EXE требует папок `assets`, `data`, `licenses`, `_internal` рядом.

Самопроверка EXE не использует обычный профиль:

```powershell
./dist/Lexora/Lexora.exe --self-test "$env:TEMP/lexora-selftest.json"
```

Опциональный третий аргумент — папка уже скачанной EN → RU модели для проверки
перевода. Самопроверка показывает тестовые окна; её JSON может содержать сведения
о мониторах и пути traceback при ошибке. Просмотри его перед публичной отправкой.

## Выпуск

Состояние экранного перевода в техническом отчёте содержит только счётчики и признаки
фокуса/видимости. `overlay_above_game` проверяет публичный порядок окон Windows,
но не доказывает видимость слоя в эксклюзивном fullscreen. Восстановление слоя
меняет только HWND Lexora с NOACTIVATE; окно и процесс игры не изменяются.

Код и подготовку словарей размещай в репозитории. EXE, portable и архив
соответствующих исходников зависимостей прикладывай к Releases вместе с SHA256SUMS.
Прочитай `THIRD_PARTY.md`: для LGPL-компонентов сохраняется доступ к исходникам
и возможность заменить динамические библиотеки. Не добавляй профиль, модели,
внутренние рабочие материалы и `.git` в архив исходников выпуска.
