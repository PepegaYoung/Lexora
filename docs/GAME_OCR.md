# Lexora Game OCR v2

Дополнительный локальный движок английского OCR на основе en_PP-OCRv4_mobile_rec.
Выбор: Настройки → Распознавание → Движок OCR → Lexora Game OCR → Сохранить.
Windows OCR остаётся движком по умолчанию. Профиль подготовки изображения выбирается отдельно.

## Что обучено

100 вручную сверенных фрагментов из 11 исходных кадров, 1800 вариантов этих
фрагментов и 6000 синтетических строк с 25 установленными шрифтами — 7900 примеров.
Игры обучения: The Witcher 3, Skyrim, Cyberpunk 2077, Baldur's Gate 3,
Stardew Valley, Hades, Team Fortress 2, Europa Universalis IV, Delta Force и Deadlock.
Автоматически распознанные подписи без ручной проверки не использовались как разметка.

Шесть эпох на RTX 4070 Super; выбрана третья. Общие признаки символов сохранены:
backbone заморожен, ответы исходной модели используются для регуляризации.
В финальные веса внесено 25% полученного обновления. Доля выбиралась на проверочных
кадрах по строгим ошибкам символов и числу полностью правильных строк.
Это одна модель при распознавании, без второго прохода нейросети.
Детектор расположения текста не переобучался.

## Проверка результата

На 53 проверочных строках из восьми отдельных кадров распознавание строк
без детектора: 16 → 13 ошибок
на 1136 символов; полностью правильных строк 42 → 44.
Эти кадры участвовали в выборе весов и не являются независимым тестом.
В старой разметке Skyrim исправлена ошибка транскрипции; исторические оценки v1
на прежней разметке напрямую с этими числами не сравниваются.

Фактический движок приложения, включая детектор, DirectML и восстановление узких
строк, проверен отдельно. На 89 контрольных полях из семи кадров: 14 → 12
ошибок после приведения регистра и пробелов, 14 → 12
при строгом сравнении; правильных строк без учёта регистра 80 → 81.
Этот набор повторно проверялся после отклонения более агрессивного обновления,
поэтому используется для регрессий, а не как новая независимая оценка.
Проверенные строки и характеристики Ведьмака не ухудшились.

После фиксации финальных весов вручную сверены ещё 34 поля трёх новых кадров
The Witcher 3, Cyberpunk 2077 и Stardew Valley. Они не использовались для обучения
или выбора модели. Строгих ошибок: 10 → 8;
полностью правильных строк: 27 → 27.
Это небольшой тест, его результаты нельзя переносить на все игры и шрифты.

На одинаковых полноразмерных кадрах медиана OCR: 235.0 →
240.8 мс. Полный повторный прогон 1000 скриншотов 42 игр:
177.4 мс, нарушений проверяемой геометрии — 0.
Для всех 1000 кадров ручной транскрипции нет; CER/WER всего набора не заявляются.
В одном ранее пустом кадре HELLDIVERS 2 найдено ложное слово на решётке предмета.
Это известное ограничение экспериментального движка, а не правильно распознанная надпись.
Это измерения на статических снимках, не оценка FPS или нагрузки в живой игре.

## Работа в приложении

ONNX Runtime DirectML, GPU по умолчанию для Game OCR; доступен CPU с двумя потоками.
При отказе GPU применяется CPU с явным отображением фактического устройства.
Модель загружается один раз по требованию. Координаты слов получаются из CTC alignment.
Веса хранятся под прежним именем game-en-v1.onnx для совместимости; фактическая
версия и SHA-256 указаны в assets/ocr/MODEL_CARD.json.
Для работы не нужны Paddle, CUDA, аккаунт или сетевые запросы.
Движок получает изображение и не обращается к памяти или файлам игры.

## Повторное обучение

scripts/train_game_ocr.py выполняется в отдельной среде с PaddlePaddle GPU 3.2.2,
OpenCV и rapidfuzz. Исходный PaddleOCR закреплён на revision из MODEL_CARD.json.
train.json, validation.json и test.json содержат image, text, screen и kind.
Разделяйте данные по исходному кадру до создания вариантов изображений.
Не используйте результаты OCR без ручной проверки как правильные подписи.

Параметры адаптации v2: --resume --epochs 6 --batch 6 --learning-rate 0.000003
--seed 641 --selection-normalized --freeze-backbone --anchor-weight 0.2 --no-export. Отбор третьей эпохи
выполнялся по нормализованной проверке, затем доля обновления — по строгой проверке.
После проверки качества экспортируйте исходный checkpoint с --export-only
--blend-checkpoint ADAPTED_CHECKPOINT --blend-fraction 0.25.
Экспорт выполнялся отдельно на CPU: PaddlePaddle 3.1.1, Paddle2ONNX 2.0.2rc3,
recognition.json + recognition.pdiparams, opset 17.

Обучающие изображения, разметка пользователей, установленные шрифты,
Paddle/CUDA и временные checkpoint не включены в portable или исходный архив.
RapidOCR 1.4.4 поставляется с Apache-2.0, под windowwords/_vendor/rapidocr.
Источники и происхождение моделей — в MODEL_CARD.json и THIRD_PARTY.md.
