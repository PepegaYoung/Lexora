# Безопасность

Проверяется текущая версия 0.6.1. Проект на ранней стадии; срок ответа на
сообщения и независимый аудит безопасности пока не заявлены.

Если в репозитории включена GitHub Private Vulnerability Reporting, используй
Security → Report a vulnerability. Не публикуй ключи, токены, cookies, личные
резервные копии и способы эксплуатации в публичном issue. Если приватный канал
не включён, сначала запроси у владельца способ приватного сообщения без секретов.

Ключи хранятся локально под Windows DPAPI. Онлайн-сервисы получают выбранный
текст. Политика данных: [PRIVACY.md](docs/PRIVACY.md). Допуск конкретного античита
не подтверждён и не гарантируется. Сборки пока не подписаны сертификатом.
