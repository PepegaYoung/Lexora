# Изменения

## 0.6.2 — 2026-10-08

- GPT-модели загружаются автоматически при запуске, подключении и выборе переводчика; список обновляется раз в пять минут на открытой вкладке. Ручной ввод ID заменён выбором модели.
- При следующем входе регистрация подключения прежней версии получает имя Lexora; действующие данные сохраняются до успешного входа.
- Горячие клавиши: Mouse4/Mouse5, сочетания с ними, NumPad и знаки пунктуации. Запись через временный обработчик ввода поддерживает занятые Alt+Z/Alt+R.
- Занятые Windows-сочетания обрабатываются внешним обработчиком клавиатуры; игровые файлы и процессы не изменяются. Чужой оверлей может потребовать отключить его совпадающую привязку.
- Карточка 440 × 440: компактные кнопки и отступы, без кнопки статьи в Викисловаре. Настроенные размеры сохранены; прежний размер по умолчанию уменьшен.
- Если под выбранным словом нет места, карточка открывается сверху. Учтены границы и отрицательные координаты мониторов.

## 0.6.1 — 2026-10-08

- Одиночная клавиша или сочетание для каждой команды.
- До четырёх альтернатив: добавление и удаление через «+» / «−».
- Проверка повторяющихся привязок; Escape отменяет запись.
- Одиночные клавиши освобождаются в обычных окнах Lexora для ввода текста.
- README, руководства, шаблоны issue, CI и чистые пакеты для публикации.

## 0.6 — 2026-10-08

- Повторение сохранённых слов с локальным расписанием.
- Произношение английским голосом Windows.
- Опциональный автоматический перевод карточки и профили активной игры.
- Диагностика задержек, резервная копия слов/настроек и установщик без администратора.

## 0.5

- Название Lexora, логотип и русский Викисловарь.
- Полноэкранные окна разбора, автокарточка и компактная контекстная помощь.
