# Участие в Lexora

Для проблемы опиши версию Windows/Lexora, режим окна, переводчик и короткие шаги
воспроизведения. Пример текста может быть вымышленным. Если прикладываешь снимок,
убери личные окна, пути, логины и ключи. Не прикладывай копию профиля.

Для изменений создай ветку, проверь соответствующие тесты и опиши наблюдаемое
поведение до и после. Инструкция: [DEVELOPMENT.md](docs/DEVELOPMENT.md).
Для сообщений безопасности используй [SECURITY.md](SECURITY.md).

Код проекта принимается на условиях MIT; данные и зависимости сохраняют свои
лицензии. Избегай инъекций в игру, чтения игровой памяти, обхода античитов,
извлечения браузерных cookies и скрытой отправки пользовательских данных.
